## What remains to verify

For each production release, compare the configured program address and deployed binary or release identity with the reviewed scope. Record the date and evidence. Do not infer a match from a program name alone.

This page does not claim that every deployed dependency matches every reviewed commit. It also does not claim that the full Loyal product has received an external audit.

Use [Networks and deployments](/build/networks-and-deployments) for configured identities and verification dates.
