Private transfers combine Loyal's Solana program with [MagicBlock Private Ephemeral Rollups](https://docs.magicblock.gg/pages/private-ephemeral-rollups-pers/introduction/authorization). Base Solana holds the token vault and settled program state. A delegated deposit can use the private runtime for balance updates.

## One lifecycle

<Steps>
  <Step title="Fund on base Solana">
    Create the user's deposit record and move tokens into the program vault. The deposit records the user's amount; the vault holds the SPL tokens.
  </Step>
  <Step title="Grant private access">
    Create the PER permission, then delegate the deposit account to the configured private validator.
  </Step>
  <Step title="Transfer inside PER">
    Update delegated deposit balances by wallet address or Telegram username. These private instructions change accounting state; they do not move tokens out of the base-layer vault.
  </Step>
  <Step title="Settle and withdraw">
    Undelegate to commit the private state back to base Solana. A separate withdrawal moves tokens from the vault to the user's token account.
  </Step>
</Steps>

## State and custody boundary

| Account | What it records | Where it is used |
| --- | --- | --- |
| `Deposit` | Amount assigned to one wallet and mint | Base Solana or PER, depending on delegation state |
| `UsernameDeposit` | Amount assigned to one Telegram username and mint | PER transfers and verified claims |
| `Vault` | The actual SPL tokens for one mint | Base Solana |

A deposit must be in the right domain for the requested instruction. Funding and withdrawal require base-layer ownership. Private transfers require delegation to PER. The SDK checks this boundary before preparing the operation.

## Telegram claims

A username transfer does not give any wallet an immediate claim. The recipient first creates a verified Telegram session through the separate `telegram-verification` program. The claim instruction checks that the session is verified, belongs to the claiming wallet, and names the same username as the deposit.
